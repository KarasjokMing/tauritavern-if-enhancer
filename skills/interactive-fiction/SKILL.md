# 互动小说条目与记忆规范

这份 Skill 用于互动小说项目的设定沉淀：把聊天里已经发生的内容，
整理成能被酒馆稳定触发的世界书条目，并维护一份长期有效的记忆。

## 使用时机

- 作者要求「收录某人」「整理某地的设定」「写入世界书」。
- 剧情中出现新人物、新地点、新势力，需要沉淀为可复用设定。
- 需要总结剧情、检查前后矛盾、更新人物经历。

## 一、条目类型与子类

| 类型 | 子类 | 承载信息 |
| --- | --- | --- |
| 世界观 | — | 世界规则、力量体系、社会结构；不含具体区域与角色 |
| 扮演准则 | — | 叙述风格与行为约束，写「怎么演」不写「是什么」 |
| 地理 | `region` / `scene` / `faction` | 区域概览 / 场景详情 / 势力详情 |
| 时间线 | `history` / `plot` | 历史节点 / 当前剧情进度 |
| 角色 | `basic` / `personality` / `tri_faceted` | 核心角色的档案、性格、不同压力下的表现 |
| NPC | — | 功能性配角，只给简要信息 |
| 事件 | — | 单次或条件触发的事件 |

判断物品归属：世界规则级 → 世界观；区域或势力专属 → 地理 `faction`；
角色专属 → 角色 `basic`；其余按出现时机归入时间线 `plot`。

## 二、条目粒度

- 一个条目只承载一类信息；同一类信息在不同条件下表现截然不同时，拆成独立条目。
- 同一目录下条目超过 5 个时考虑再分组。
- 删留判断（逐句问自己）：删掉这句，AI 会不会出错？不会 → 删。
- 是信息还是装饰？装饰 → 改写或删。
- 条目正文超过 2400 字时，考虑拆分。

## 三、关键词（触发词）规则

- **严禁单个汉字**：`樱` 会命中所有含「樱」的句子，必须写成 `小樱`。
- **避免泛用职务**：`老师` → `语文老师`；`会长` → `学生会长`。
- **避免成语**：`倾国倾城`、`闭月羞花` 之类会导致无关触发。
- 人物条目的关键词必须包含人物名本身；三字全名是安全的。
- 不同条目之间尽量不要共用关键词；共用时改用更精确的词组。

## 四、条目正文写法

- **数据库格式优先，不是散文**：用键值对与列表，不用段落。
- 只写偏离默认认知的信息。真实世界里 AI 已知的内容不必写。
- 外貌写「特征」不写「美」：遮住名字也能认出是谁。
- 背景写关键经历，不写编年史：删掉它，角色行为会不会变？不会就删。
- 语料（台词）只保留纯对话，删掉混入的动作、表情与心理描写。
- **禁止占位符**：不写「某城市」「某组织」；不确定时标注需要作者确认。
- 统一起见，正文一律使用简体中文。
- 不写「详见某条目」「与某条目配套」这类交叉引用：每个条目必须独立可读。

## 五、质量自检清单

写入前逐条核对：

1. 条目名、文件名、引用的名称是否一致。
2. 关键词是否命中第三节的禁忌。
3. 正文是否混入制作说明（「本卡独家」「戏剧用途」「AI 写作要点」等）。
4. 是否出现破折号（`——`）；出现即改写为逗号或断句。
5. 是否出现八股表达（「嘴角微微上扬」「眼中闪过一丝…」）与模糊词（「似乎」「仿佛」「宛如」）。
6. 不同条目对同一对象的外貌、性格、关系描述是否矛盾；关系描述是否双向一致。

## 六、长期记忆维护

记忆是「仍然有效」的事实集合，与故事正文分开维护。固定五段：

```
## 摘要
## 人物状态
## 未完成线索
## 当前场景
## 已失效事实
```

- 每条一行，简短直接；不要复述整段剧情。
- 被作者否认或被后续剧情推翻的事实，移入「已失效事实」，不要直接删除，便于回溯。
- **作者修改优先**：作者否定某项设定后，正文、世界书与记忆必须一起改，
  不允许只在其中一处改而让别处继续保留旧事实。

## 七、记忆与条目的关系

- 重要且长期有效的人物、地点、势力 → 世界书条目。
- 剧情推进与状态变化 → 记忆。
- 即将用完的临时线索 → 记忆的「未完成线索」，用完后删除。
